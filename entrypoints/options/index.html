Your keys are protected. Unlock them under Key protection to view or change them.

Prices for cost estimates (optional)

Enter your provider's current prices in US dollars per million tokens. PageCraft doesn't ship prices because they change; without them it shows token counts only.

API key protection

Optionally encrypt your API keys with a passphrase. You'll enter it once per browser session. This protects keys on disk; it can't protect against malware on an unlocked computer.

If you forget it, you'll need to enter your API keys again. There is no recovery.

    What gets sent

    When you press Generate or Review, PageCraft sends your instructions, the recent conversation, your current theme (when refining) and a short page description (URL without query string, title, DOM outline, colors, fonts, CSS variables) to the selected provider. Review also sends a contrast report (element descriptions and colors, no text). With “Send screenshot” on, a downscaled screenshot of the visible part of the page is sent too, and it can show page text. Nothing is sent anywhere else.
