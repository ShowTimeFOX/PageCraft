# Changelog

Notable changes to PageCraft are documented here.

## [1.1.0] - 2026-11-15

### Added

- AI theme generation in the CustomStyle editor: describe a theme, stream CSS into the editor, refine it, stop mid-way.
- Providers: Anthropic, OpenAI (and compatible), Google Gemini, and local OpenAI-compatible servers (Ollama, LM Studio).
- AI settings page with model listing and connection test.
- Live preview of unsaved CSS on the site's tab.
- Page digest (structure, colors, fonts, CSS variables) to give the model context.
- Sanitizer that strips `@import` and external `url()` references from generated CSS.
- `docs.html` developer documentation and roadmap.

### Changed

- Migrated to WXT + TypeScript; builds Chrome MV3 and Firefox MV3 from one codebase. Requires Node.js 22+.
- Replaced the ComfyUI placeholder with the LLM provider layer.

### Removed

- `manifest.js` / hand-maintained `manifest.json` (generated by WXT now).

## [1.0.0] - 2026-10-18

### Added

- Initial Chrome and Firefox extension using Manifest V3.
- Compact popup controls for enabling PageCraft and selecting global dark/light presets.
- Named custom style editor with per-host style selection.
- Local storage and automatic style application when a site loads.
